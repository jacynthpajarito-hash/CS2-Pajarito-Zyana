# DOCUMENT v1 & v2

## Electricity bill calculator

## Description
-the program calculates your electricity bill.

## Version 1: Original code without input validation
-input: asks for a name, your previous and current meter readings
-Process: Calculates your total bill
-Output: Your current bill 

## Version 2: Revised code with validation
-input: asks for your name, your previous and current meter readings
-Validation: if name is empty, then will ask for valid name again and again until valid name is given.
-Validation: if previous reading is less than 0, then will ask for valid value over and over until value is fixed.
-Validation: if current reading is less than 0 and smaller than previous reading, then will ask for number over and over until value is fixed.
-Process: Calculates your total bill.
-Output: energy consumption and total electricity bill
